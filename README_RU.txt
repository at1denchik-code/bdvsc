ПРОЕКТ EnterpriseLinQ — C# Windows Forms + .NET 9 + SQLite + LINQ
Целевая платформа: .NET 9 (net9.0-windows), Visual Studio 2022.

ВАЖНО
Для .NET 9 требуется Visual Studio 2022 версии 17.12 или новее и установленный .NET 9 SDK. В Visual Studio Installer проверьте компонент «Разработка классических приложений .NET».

КАК ОТКРЫТЬ
1. Распакуйте архив в отдельную папку.
2. Откройте EnterpriseLinQ.sln в Visual Studio 2022.
3. Дождитесь восстановления NuGet-пакетов. Используется Microsoft.Data.Sqlite 9.0.0.
4. Нажмите F5 для запуска.
5. При первом запуске рядом с приложением создаётся enterprise.db и заполняется тестовыми данными.

В проекте есть 4 вкладки: реестр продаж с фильтрами, статистика, операции множеств и пагинация.
Демонстрация Deferred/Immediate показывает изменение IEnumerable при добавлении в исходный List<Sale>; это не добавляет строку в SQLite.

Форма создаётся программно в FormMain.cs, поэтому её визуальная разметка не редактируется в дизайнере Visual Studio. Интерфейс появляется при запуске приложения.
